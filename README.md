# savtain
SIEN1000 Assignment 2 - Fresh Off The Boat
This project is a mountain rescue coordination application prototype that helps rescuers manage incidents, view weather conditions, receive equipment reccomendations, submit reports, and coordinate rescue operations through a centralised system.

The purpose of this project is to improve the efficiency, safety, and coordination of mountain rescue operations by providing rescuers with a centralised platform for incident reporting, operation management, weather monitoring, navigation and communication. The goal is to reduce delays, improve access to critical rescue information, and support rescuers in high-pressure emergency situations. The project solves problems such as poor coordination between rescuers, lack of real-time operational updates, limited access to weather and equipment guidance, and inefficient communication during emergency rescue missions.
